# PortfolioHUB

Portfólio acadêmico e profissional de **Caroline Machado de Oliveira**, estudante do 8º semestre de Ciência da Computação no CEUB (Centro Universitário de Brasília).

Este repositório reúne, em um só lugar, os projetos que desenvolvo na faculdade e fora dela. Ele é a evolução do **Study Hub**, planejado na Fase 1 do Bootcamp I.

🌐 **Página do portfólio (GitHub Pages):** https://carololivert.github.io/PortfolioHUB/
💼 **LinkedIn:** https://www.linkedin.com/in/caroline-m-oliveira-b0329b176

## Estrutura do repositório

```
PortfolioHUB/
├── index.html                  # Página publicada no GitHub Pages
├── assets/                     # Imagens e arquivos usados pela página
│   └── img/
├── academicos/                 # Projetos e materiais das disciplinas
│   ├── bootcamp-i-study-hub/
│   ├── projeto-integrador-4-karaoke-ia/
│   ├── testes-qualidade-software/
│   ├── seguranca-digital/
│   └── sistemas-tempo-real-embarcados/
├── pessoais/                   # Projetos fora da faculdade
│   └── automacao-relatorios-python/
├── documentacao/               # Documentos e slides das entregas
├── CHANGELOG.md                # Histórico de versões
└── README.md
```

Cada pasta de projeto tem o seu próprio `README.md`, com objetivo, tecnologias, status e o que está guardado ali.
