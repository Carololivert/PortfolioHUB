# Segurança Digital

**Disciplina:** Segurança Digital · **Semestre:** 8º · **Status:** em andamento

## Objetivo

Reunir anotações, laboratórios e estudos sobre vulnerabilidades, proteção de redes e de dados. É um conteúdo que uso no dia a dia, já que trabalho com redes e com relatórios que envolvem dados de clientes.

## O que está nesta pasta

| Pasta / arquivo | Conteúdo |
| :--- | :--- |
| `anotacoes/` | Anotações das aulas |
| `laboratorios/` | Registros das práticas de laboratório |
| `vulnerabilidades/` | Estudos de vulnerabilidades |

## Conteúdos

- Proteção de redes
- Proteção de dados
- Vulnerabilidades e como mitigá-las

## Aprendizados

- Segurança precisa ser pensada junto com a infraestrutura e com o código, e não depois.
