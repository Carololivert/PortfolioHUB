# Study Hub — Bootcamp I

**Disciplina:** Bootcamp I · **Semestre:** 8º · **Status:** em andamento

Planejar um lugar único para reunir tudo o que produzo na faculdade, com uma organização simples o bastante para conseguir manter ao longo do curso. O Study Hub deu origem a este repositório, o PortfolioHUB.
