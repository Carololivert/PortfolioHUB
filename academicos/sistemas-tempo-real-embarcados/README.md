# Braço Mecânico — Sistemas em Tempo Real e Embarcados

**Disciplina:** Sistemas em Tempo Real e Embarcados · **Semestre:** 8º · **Status:** em desenvolvimento

## Sobre o projeto

Montagem de um **braço mecânico** controlado por um sistema embarcado, que responde a comandos em tempo real.

## O que está nesta pasta

| Pasta / arquivo | Conteúdo |
| :--- | :--- |
| `codigo/` | Código que controla o braço |
| `esquemas/` | Esquemas de ligação e montagem |
| `registros/` | Fotos e vídeos da montagem |

## Tecnologias

<!-- Ex.: Arduino, ESP32, servomotores, C/C++ -->

## Aprendizados

- O lado físico da computação: como o software controla um dispositivo real.
- Sistemas de tempo real precisam responder dentro de um prazo, e não só dar a resposta certa.
