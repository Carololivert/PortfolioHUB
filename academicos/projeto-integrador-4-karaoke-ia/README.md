# Karaokê com IA — Projeto Integrador 4

**Disciplina:** Projeto Integrador 4 · **Semestre:** 8º · **Status:** em desenvolvimento · **Tipo:** projeto em grupo

## Sobre o projeto

Um karaokê que usa inteligência artificial para **separar o vocal do instrumental** das músicas e exibir a letra, permitindo cantar qualquer música sem precisar de uma versão karaokê pronta.

## Funcionalidades

- Separação de vocal e instrumental com modelos de IA de separação de áudio
- Exibição da letra da música

## Tecnologias

- Python
- Modelos de IA para separação de áudio
