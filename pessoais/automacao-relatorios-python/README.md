# Automação de Relatórios em Python

**Tipo:** projeto profissional · **Status:** em uso

## Contexto

Trabalho com redes em um provedor de internet em Planaltina-DF. Vários relatórios de controle precisavam ser gerados com frequência e eram feitos todos à mão.

## O que foi feito

Scripts em Python que geram esses relatórios automaticamente, substituindo por código um trabalho que antes era manual e repetitivo.

## Resultados

- Menos tempo gasto em tarefas repetitivas
- Menos erros de digitação e cópia
- Relatórios no mesmo padrão toda vez

## Tecnologias

- Python
- Integração com sistemas e APIs da empresa

## Observação

O código desta automação não está publicado porque acessa sistemas e dados de clientes da empresa. Esta pasta documenta o projeto, o problema e a solução.
